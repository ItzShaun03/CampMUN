# CampMUN content folder

Everything you drop into the two folders below is shown on the website automatically — no configuration needed.

## images/

Put photos here (jpg, jpeg, png, webp, gif, svg, avif).

They fill the **home-page gallery**. The first image goes into the first block, the second into the second block, and so on. Blocks with no matching image stay as empty placeholders.

## documents/

Put files here (pdf, doc, docx, txt, ppt, pptx, xls, xlsx, csv, odt, md).

Each file appears as a **downloadable card on the Resources page**, using its filename as the title.

## Tips

- Sort by name if you want a specific order: `01-opening.jpg`, `02-sessions.jpg`.
- Replace a file with the same name and the site picks up the new version.
- The site reads image/document sizes at load time; large photos are fine but smaller images load faster.
